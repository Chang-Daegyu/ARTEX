## 실행 구조 보존 검사

### Go

Go **1.26.3**의 표준 `go/parser`, `go/scanner`로 모든 원본·수정본 Go 파일을 읽었습니다.
주석을 제외한 토큰 종류, 문자열, 식별자, 연산자, 자동 세미콜론 순서가 일치했습니다.
`//go:`, `// +build`, `//line` 특별 지시문도 따로 비교했습니다.

결과: **325개 PASS**, 문법 오류·실행 토큰 차이·특별 지시문 차이 0개.

### 프런트엔드와 JavaScript

Babel parser로 JS·TS·TSX·MJS를 파싱하고 주석·위치 메타데이터를 제외한 AST를
비교했습니다. JSX 문구·문자열·타입·표현식·명령을 그대로 비교했습니다.
PostCSS로 CSS의 주석·소스 위치를 제외한 규칙·선택자·값을 비교했습니다.

결과: **JS 계열 193개 PASS, CSS 5개 PASS**.
CSS 프리셋의 원본 이름/키 메타데이터와 추출되는 주요 색도 동일합니다.

### Python·셸·SQL·설정

- Python 4개: 표준 AST에서 주석·줄 번호를 제외한 구문 구조 동일.
- 셸 6개: `bash -n` 문법 확인 및 기존 비주석 내용 동일.
- 배치·Dockerfile·환경 예제·훅: 실행하는 기존 행 보존.
- SQL: 문자열·달러 인용 함수 본문을 포함한 **8,284개 비주석 토큰 동일**.
- YAML 3개: 파싱한 데이터 구조 동일.
- JSON 10개: 데이터 구조 동일. 설정 예제의 `_comment*` 번역만 비교에서 제외.
- Git diff 검사: 원래 CRLF 파일을 존중하도록 `core.whitespace=cr-at-eol`로 공백 검사.

`.gitignore`의 `/docs/` 제외 규칙은 한국어 문서를 버전 관리하기 위해 해제했습니다.
이는 의도한 저장소 관리 변경이며 애플리케이션 실행 코드 변경이 아닙니다.

## 실행하지 않은 항목

이번 목적은 전체 소스 이관과 문서·주석 한국어화입니다. 다음은 수행하지 않았습니다.

- ARTEX 서비스·에이전트·실제 대상 작업 실행
- 실제 LLM·MCP·네트워크 점검 도구 호출
- PostgreSQL 연결·스키마 적용·통합 테스트
- 앱 의존성 전체 설치를 전제로 한 전체 타입 검사·Next 정적 빌드
- Docker 이미지 빌드·게시·배포, 태그 발행, 자동 업데이트
- 외부 알림 전송, 관리자 암호 변경

PASS는 **이번 변경이 실행 구문을 바꾸지 않았다는 정적 검증 결과**입니다.
원본 프로그램의 모든 기능·성능·보안을 실행 환경에서 검증했다는 뜻은 아닙니다.
기능을 수정할 때는 [개발 문서](development.md)의 전용 DB와 관련 테스트를 추가로 수행하세요.

## 독립 저장소 이관 방식

GitHub Fork 기능 없이 기존 비공개 `Chang-Daegyu/ARTEX`에 파일 스냅샷을 반영합니다.
원본 저작자·라이선스·출처는 유지합니다. GitHub Issues, PR, Secrets, 계정 설정,
릴리스 첨부, 원본 전체 과거 커밋 이력은 소스 파일 이관 대상이 아닙니다.

업로드는 파일 모드와 Git blob 내용으로 트리를 구성하고, 최종 원격 tree SHA를
로컬 Git tree와 비교합니다. 이 검사는 전체 파일 내용·경로·실행 비트를 함께 확인합니다.
